# AI Meeting Summarizer — Frontend

React 18 + Vite meeting UI (Google Meet–style).

**Repository:** [https://github.com/Muhammad-Umar-Waqar/Ai-Meeting-Summarizer-Frontend](https://github.com/Muhammad-Umar-Waqar/Ai-Meeting-Summarizer-Frontend)

```bash
git clone https://github.com/Muhammad-Umar-Waqar/Ai-Meeting-Summarizer-Frontend.git
cd Ai-Meeting-Summarizer-Frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Stack

- React 18
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Framer Motion

## Vercel

`vercel.json` rewrites all routes to `index.html` so `/lobby` and `/room` do not 404 on refresh or back.
